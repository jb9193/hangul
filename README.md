# 우리 한글 교실

70~80대 어르신을 위한 기초 한글 학습 웹앱입니다. 휴대폰에서 바로 열어 쓰실 수 있습니다.

**바로가기: https://jb9193.github.io/hangul/**

## 배우는 내용
- **기초 학습** — 1단계 자음, 2단계 모음, 3단계 소리 합치기(그+아=가), 4단계 받침 읽기
- **글씨 쓰기 연습** — 자음·모음 24자의 쓰는 순서를 움직이는 그림으로
- **글자 한눈에 보기** — 자음·모음을 골라서 소리로 익히기
- **낱말 배우기** — 생활 낱말 761개, 15개 갈래
- **낱말 맞히기 놀이** — 그림과 소리를 듣고 낱말 고르기

모든 글자와 낱말은 성우 음성으로 들려 드립니다.
